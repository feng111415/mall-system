# V0.5 模块 3 账号与隐私静态模型

问题：在保持商城 C1+ 青春波普视觉的前提下，账号与隐私独立页面应使用什么信息结构？

已确认的业务规则：

- 更换手机号必须依次验证旧手机号和新手机号。
- 更换成功后下线全部设备，会员使用新手机号重新登录。
- 注销前检查未完成订单和处理中售后；通过当前手机号验证码后立即停用账号。
- 注销后保留履约、售后和财务审计所需交易凭证，不物理删除交易记录。
- 当前没有会员余额和非必要营销授权，不在模型中虚构余额拦截或授权开关。

最终模型采用用户确认的 **A 总览结构 + C 生命周期**：

- 左侧保留会员身份、登录手机号、在线设备和最近登录概览。
- 右侧依次展示登录手机号、授权与协议记录、账号生命周期和注销账号。
- 生命周期只承载可查看的身份、授权和安全事件；敏感写操作不混入时间轴。
- 注销固定在页面末端，保持独立危险操作层级。

本目录为一次性静态模型，不连接真实接口。最终页面需按该信息层级重写为正式 Vue 页面，不直接复制原型代码。
