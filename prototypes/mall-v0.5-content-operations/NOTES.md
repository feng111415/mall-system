# V0.5 模块 1 静态模型

问题：在保持 C1+ 商城视觉的前提下，首页内容运营在若依后台应该采用什么信息结构？

当前约束已确认：

- 可运营内容包含主视觉、公告条、推荐专区和商品排序。
- 主视觉保持 C1+ 左文案右双图拼贴。
- 内容支持草稿、预览、定时发布和停用。
- 推荐商品人工优先，失效后按销量自动补位。
- 运营主管和商品运营可管理，其他岗位不显示菜单。

模型变体：

- `?variant=A`：预览工作台，编辑与实时预览并排。
- `?variant=B`：内容清单，优先批量查询和排期管理。
- `?variant=C`：页面编排，优先区块顺序和推荐位结构。

最终结论：

- 采用 **B + A** 组合。
- B 内容清单作为页面内容管理首页。
- A 预览工作台作为新增和编辑页。
- 不采用 C 自由编排，首页区块顺序保持固定。
- 2026-08-05 停在模型确认阶段，正式实现从下一次开发继续。

本目录为一次性静态模型，确认结构后删除未采用的变体，再将结论吸收到正式若依页面和商城首页代码。
