# 商城静态原型

> PROTOTYPE - 可删除的设计验证稿。确认后，应将选中方案重写进正式 Vue 3 工程，不直接复用本文件代码。

## 验证范围

1. 用户端首页的信息密度和导航结构。
2. 商品、SKU、购物车、结算、订单和售后的完整流程。
3. 管理后台是否适合运营、仓库、客服和风控人员反复使用。

## 首页方案

- `?variant=A`：陈列型，突出主题陈列与商品网格。
- `?variant=B`：分类型，突出快速筛选和横向商品列表。
- `?variant=C`：任务型，突出搜索、快捷入口和紧凑推荐。

页面底部可切换方案，也可使用键盘左右方向键。所有交互状态只保存在内存，刷新即重置。
