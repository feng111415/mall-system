# 商城 V0.3 风格细化原型

> PROTOTYPE - 可删除的视觉验证稿，不接真实接口，不得直接合并到正式商城代码。

## 要回答的问题

在已经确认的方案 C 配色基础上，登录焦点态、桌面/移动导航、商品图片标签和标题字体应采用哪种细化方向。

## 三个方向

- `?variant=c1`：复古波普杂志。粗黑编辑字体、栏目式导航、纸张标签和硬阴影焦点态。
- `?variant=c2`：日系潮玩商店。圆润标题字体、彩色分区导航、贴纸标签和更亲切的表单结构。
- `?variant=c3`：轻运动街头。紧凑运动字体、深色编号导航、号码牌标签和会员通行证布局。

## 推荐组合稿

- `?variant=c1plus`：C1+ 青春波普商店。以 C1 为骨架，吸收 C2 的圆润标题气质和 C3 的高对比商品标签规则；正文继续使用清晰黑体。
- C1+ 当前只用于确认最终静态样式，尚未进入正式商城。

使用页面底部左右箭头或键盘方向键切换方案。每个方案的手机号输入框会自动聚焦，便于直接比较焦点效果。

## 待确认

- 最终主方案：C1+ 候选，待用户确认静态模型。
- 需要混用的导航、字体、标签或表单元素：待用户说明。
