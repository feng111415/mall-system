# 若依 500 登录问题诊断

## 现象

登录接口 HTTP 层返回 200，但 JSON 为：

```json
{"code":500,"msg":"验证码已失效"}
```

若依把业务校验失败统一使用 `code=500` 返回，这不等同于服务器启动失败。

## 根因

若依默认开启验证码。登录请求必须同时携带验证码图片对应的 `code` 和 `uuid`：

1. 先请求 `GET /captchaImage`。
2. 读取返回的 `uuid` 和图片中的验证码。
3. 使用同一组 `uuid/code` 请求 `POST /login`。

直接使用空的 `code/uuid`，或验证码过期、刷新后仍使用旧 uuid，都会返回“验证码已失效”。

验证码开关和其他系统配置会缓存到 Redis，只修改数据库中的 `sys_config` 不会立即刷新运行中的配置。应通过若依配置页面修改，或重启后端/清理对应 Redis 配置缓存后再验证。

## 已验证

- `GET /captchaImage`：HTTP 200，返回图片和 uuid。
- 空验证码登录：返回 `code=500`、验证码失效。
- 在独立测试库临时关闭验证码并重启后端：`admin/admin123` 登录成功，返回 token。
- 测试结束后已将测试库验证码配置恢复为开启。
- 原业务库 `ry-vue` 未修改。

## 正确操作

打开前端登录页时让页面自动加载验证码，输入图片中的验证码后再点击登录。不要复用旧验证码，也不要手工只调用 `/login` 而省略 `/captchaImage`。
