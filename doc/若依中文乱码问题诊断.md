# 若依中文乱码问题诊断

## 现象

管理后台菜单、部门、用户昵称显示为 `????`。

## 根因

测试库导入时，PowerShell 文本管道将 UTF-8 SQL 转换为系统代码页，MySQL 客户端又按 GBK 接收，中文在写入数据库前已变成问号。数据库字段虽然是 `utf8mb4`，但原始内容已经损坏，前端无法恢复。

## 修复与验证

- 使用 UTF-8 原始字节流导入 SQL，并指定 MySQL 客户端 `--default-character-set=utf8mb4`。
- 重建独立测试库 `mall_migration_test_20260728`，原库 `ry-vue` 未修改。
- 菜单名称十六进制已确认是 UTF-8，例如“对账与告警”。
- `POST /login` 返回 200。
- `GET /getRouters` 返回 200，路由菜单数据正常。
- 测试库验证码配置已恢复为开启。

## 后续导入规则

不要使用会改变编码的 PowerShell 文本管道导入中文 SQL。使用 Navicat 的 UTF-8 导入，或使用 MySQL 客户端的 UTF-8 字节流并显式指定 `--default-character-set=utf8mb4`。
