## 商城 V0.3：模块 5 会员会话与设备安全（2026-07-31）

- 浏览器使用随机持久设备标识；设备类型由后端 User-Agent 判定，平板计入移动端。
- 每会员最多同时在线 2 台移动端和 1 台电脑端；同设备轮换 Token，第三台手机保留主手机并下线普通手机，新电脑替换旧电脑。
- 首台手机为主设备；短信验证更换主设备，30 天最多 3 次，并记录只追加审计。
- Token 数据库与 Redis 定位键只保存 SHA-256 摘要；退出、替换和远程下线同步使旧 Token 失效。
- 个人中心新增登录设备列表、状态标识、远程下线和主设备短信更换。
- V2.12.0 迁移完成升级、回滚、再次升级和重复升级验证。
- 后端全量测试 123 项通过；商城生产构建、最终 JAR、健康检查和真实 3 手机 + 2 电脑链路通过。
