# 若依后台安全启动配置

## 必填环境变量

生产启动前必须由部署平台注入以下变量，不要写入 `application*.yml`、Git 或启动脚本：

```text
RUOYI_TOKEN_SECRET=<至少 64 个字符的随机值>
RUOYI_DATASOURCE_URL=<生产 MySQL JDBC 地址>
RUOYI_DATASOURCE_USERNAME=<生产数据库账号>
RUOYI_DATASOURCE_PASSWORD=<生产数据库密码>
```

如果确实需要启用 Druid 监控（生产默认不允许），还必须提供：

```text
RUOYI_DRUID_USERNAME=<非默认监控账号>
RUOYI_DRUID_PASSWORD=<非默认监控密码>
```

## 安全默认值

以下开关默认关闭，不要在生产覆盖为 `true`：

```text
RUOYI_SWAGGER_ENABLED=false
RUOYI_DRUID_STAT_ENABLED=false
RUOYI_MYBATIS_MULTI_STATEMENT_ALLOW=false
```

生产建议显式设置：

```text
SPRING_PROFILES_ACTIVE=prod,druid
```

应用启动时会拒绝缺失或过弱的 JWT/数据库配置、默认 Druid 凭据、生产诊断入口和多语句执行。

## 本地验收

本地测试库可以临时注入 `MALL_SMS_MOCK_CODE=123456`，生产不要设置该变量；未设置时短信服务使用非固定验证码策略。当前验收环境还使用 `SPRING_DATA_REDIS_PORT=28555` 和独立测试库，不能直接复制到生产。
