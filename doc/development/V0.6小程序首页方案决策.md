# V0.6 小程序首页方案决策

日期：2026-08-12

## 结论

用户已审批 **B：高频任务优先首页**，作为 V0.6 独立小程序工程的首页信息架构。

## 首页结构

1. 问候与会员状态摘要。
2. 我的订单快捷状态：待付款、待发货、待收货、待评价。
3. 高频服务：优惠券、地址簿、收藏足迹、售后服务。
4. 运营推荐位与商品列表，保留继续购物入口。
5. 固定底部 TabBar：首页、分类、购物车、消息、我的。

## 约束

- 延续已确认的 C1+ 活泼年轻视觉风格。
- 正式小程序只复用真实 `/api/mall/**` 接口，不复制 A/C 原型结构。
- 金额、库存、订单状态、售后金额和权限继续由服务端决定。
- 原型中的浮动方案切换器不进入正式工程。

## 下一步

正式编码前确认小程序技术栈（原生 WXML、uni-app 或 Taro）、微信开发者工具可用性和 AppID/测试号条件。
