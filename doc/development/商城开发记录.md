# 商城开发记录

## 第一阶段：工程基线与前后端骨架

### 已确认

- 项目名称：日常商店商城系统
- 业务类型：单商户 B2C 实物商城
- 后端形态：若依模块化单体
- 用户端：Vue 3 + Vite + Pinia + Vue Router 4 + Vant 4
- 管理端：Vue 3 + Vite + Pinia + Vue Router 4 + Element Plus
- 用户端首页：静态模型模板 A（陈列型）
- 外部服务：首期使用 Mock Adapter

### 本阶段范围

- 建立 Git `dev` 分支和基础忽略规则。
- 创建用户端与管理端独立前端工程。
- 建立前端环境变量、API 基础地址和构建脚本。
- 新增 `mall-business` Maven 模块，接入若依后端启动模块。
- 新增短信、支付、物流三个 Port 与 Mock Adapter。
- 新增匿名健康检查接口：`GET /api/mall/health`。
- 保留现有 `ruoyi-ui` Vue 2 工程，不进行迁移覆盖。
- 不修改若依公共模块；根 Maven 只增加商城业务模块的模块声明和依赖。

### 遗留问题

- Mock Adapter 目前只用于联调，不代表真实短信、支付或物流成功。
- 用户端和管理端使用 `createWebHistory`，部署 Nginx 时需要配置 SPA fallback 到 `index.html`。
- 用户端 npm 审计提示 2 个 high 风险；管理端提示 1 个 moderate、2 个 high 风险。依赖升级前需要单独评估兼容性，暂不擅自使用 `npm audit fix --force`。
- 真实启动健康接口尚未完成：本机 MySQL 拒绝项目记录的开发凭据 `root/123456`。未修改数据库密码或数据，待本机凭据恢复后执行 `GET /api/mall/health` 验证。
