# 本机数据库接入说明

## 1. Navicat 新建 MySQL 连接

- 主机：`127.0.0.1`
- 端口：`3306`
- 用户名：`root`
- 密码：`123456`

项目后端配置文件已经按上面的信息配置：

`ruoyi-admin/src/main/resources/application-druid.yml`

如果你的 Navicat 连接密码不是 `123456`，只需要改这个文件里的：

```yml
password: ${RUOYI_DATASOURCE_PASSWORD:123456}
```

把 `123456` 改成你的 MySQL 密码。当前已将本机 MySQL root 密码重置为 `123456`，并确认可以连接。

## 2. 初始化数据库

在 Navicat 里打开查询窗口，先执行：

```sql
create database if not exists `ry-vue` default character set utf8mb4 collate utf8mb4_general_ci;
use `ry-vue`;
set names utf8mb4;
```

然后右键 `ry-vue` 数据库，选择“运行 SQL 文件”，按顺序导入：

1. `ry_20260417.sql`
2. `quartz.sql`

## 3. 启动前检查

后端启动前需要确认：

- MySQL 已启动，Navicat 能连接 `127.0.0.1:3306`
- `ry-vue` 数据库已存在，并且上面的 4 个 SQL 文件都导入成功
- Redis 已启动，地址是 `127.0.0.1:6379`

若依默认账号：

- 用户名：`admin`
- 密码：`admin123`
